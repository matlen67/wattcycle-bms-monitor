Wattcycle BMS Monitor

ESP32-S3 · 16 MB Flash

⚡ Erstinstallation über USB

Installiere den Wattcycle BMS Monitor direkt über deinen Browser auf einem ESP32-S3. Es wird keine Arduino IDE benötigt.

Achtung: Eine Neuinstallation kann vorhandene Einstellungen und Daten auf dem ESP32 löschen. Verwende diese Funktion nur für die Erstinstallation oder eine bewusst gewünschte Neuinstallation.
Dieser Browser unterstützt den Webflasher nicht. Bitte Chrome oder Edge auf einem Desktop-Computer verwenden.Die serielle Schnittstelle ist hier nicht verfügbar. Bitte die Seite über HTTPS öffnen.

USB-Datenkabel erforderlich · Chrome oder Edge · Firmware für ESP32-S3

Installationsanleitung

  1. ESP32-S3 per USB-Datenkabel verbinden.
  2. Auf Installieren klicken.
  3. Den richtigen seriellen Anschluss auswählen.
  4. Die Installation bestätigen und warten, bis sie abgeschlossen ist.
  5. ESP32-S3 bei Bedarf neu starten.

Falls kein Anschluss erscheint: USB-Kabel und Treiber prüfen. Gegebenenfalls den ESP32-S3 in den Download-Modus versetzen.

↻ Firmware-Update über ElegantOTA

Du hast den Wattcycle BMS Monitor bereits installiert? Lade die Update-Firmware herunter und installiere sie über die ElegantOTA-Funktion im Webinterface deines ESP32. Ein USB-Webflasher ist für Updates nicht erforderlich.
